# 명령 해석 AI 설정

웹·터미널·MCP `say`는 공통 설정을 읽습니다. AI 선택은 실물 실행 허용과 독립적입니다.
미리보기와 기존 기기 설정을 먼저 확인하세요.

## 처음 설정하기

웹의 상단 **AI 설정**을 누르거나 터미널에서 `./kevin --setup`을 실행합니다.
설정이 없는 터미널 첫 실행에도 같은 선택이 나옵니다. Windows는 `kevin.cmd --setup`입니다.
**나중에 설정**은 화면을 둘러보는 용도입니다. MCP 직접 기기 도구에는 내부 명령 해석 모델이 필요 없습니다.

### 이 컴퓨터에서 실행

1. [Ollama](https://ollama.com/)를 설치하고 실행합니다.
2. 사용할 모델을 준비합니다. 기본 모델은 `qwen2.5:3b`이며 예를 들어 `ollama pull qwen2.5:3b`로 받습니다.
3. 로컬을 선택하고 **연결 확인**을 누릅니다. 고급 설정에서 설치한 다른 모델을 선택할 수 있습니다.
4. 확인에 성공하면 **저장하고 시작**을 누릅니다.

연결 확인은 실제 추론까지 검사합니다. 설치/다운로드를 자동 실행하지 않습니다.
로컬 모델의 구조화 출력 능력과 기기의 메모리에 따라 대화·작곡 기능의 품질과 지연이 달라집니다.

### 내 API 키로 연결

OpenAI API 키를 입력하고 **연결 확인 → 저장하고 시작**을 누릅니다.
고급 설정의 기본 모델은 `gpt-6-luna`입니다. 다른 모델은 해당 계정의 접근과 구조화 출력 지원이 필요합니다.
연결 확인은 고정 시험 문장만 전송하며 소량의 API 사용량이 발생합니다.
저장한 뒤 실제 대화에는 요청 텍스트와 필요한 대화/기기 기능 상태가 전송됩니다.
카메라·음성의 별도 연결을 선택하는 설정은 아닙니다.

키 누락·거절·할당량·연결 실패에는 다른 제공자로 자동 전환하지 않습니다.
**연결 확인됨**은 마지막 확인의 결과입니다. 이후 오류가 나면 다시 확인해야 합니다.

## 저장과 취소

- 설정을 바꾸면 기존 연결 확인 결과는 무효가 됩니다. 변경한 내용으로 다시 확인해야 저장할 수 있습니다.
- 닫기/나중에 설정/Esc는 저장된 선택을 바꾸지 않습니다. 동시 편집이 있으면 다시 열도록 안내합니다.
- 키는 브라우저 저장소·응답 JSON·URL·로그에 넣지 않습니다. 등록 여부만 화면에 표시합니다.
- 직접 입력해 저장한 키는 사용자 전용 로컬 JSON에 보관합니다. 파일은 평문이며 OS 비밀 저장소 암호화는 이 버전에 포함하지 않습니다. POSIX 파일 권한은 0600, Windows는 사용자별 AppData를 사용합니다.
- 환경변수 키는 새 설정 파일로 복사하지 않습니다.

기본 파일 위치:

| OS | 위치 |
|---|---|
| macOS | `~/Library/Application Support/KEVIN/ai.json` |
| Windows | `%APPDATA%/KEVIN/ai.json` |
| Linux | `~/.config/kevin/ai.json` |

`KEVIN_AI_CONFIG`로 격리된 설정 경로를 지정할 수 있습니다. 개인 설정 파일을 Git에 올리지 마세요.
실행 중인 웹/터미널도 다음 요청부터 저장된 설정을 읽습니다.

## 웹을 원격으로 열었을 때

GitHub Pages 등 원격 페이지에서는 **로컬 앱에서 설정 열기**로 이동합니다.
키를 받는 설정 API는 연결기와 같은 출처에서만 사용할 수 있습니다. 다른 웹사이트의 설정 조회/변경과 DNS 재바인딩 호스트를 거부합니다.
원격 페이지의 기존 기기 제어는 별도 경로이며 이 설정 API의 권한을 갖지 않습니다.

## 기존 환경변수와 우선순위

명시한 CLI `--planner` → 환경변수 → 저장된 설정 → 로컬 기본값 순서입니다.
환경변수로 고정된 항목은 화면에서 바꾼 값으로 조용히 무시하지 않고 변경을 거절합니다.

| 항목 | 환경변수 |
|---|---|
| 선택 | `KEVIN_PLANNER=ollama` 또는 `openai` |
| OpenAI 키·모델 | `OPENAI_API_KEY`, `KEVIN_OPENAI_MODEL` |
| 로컬 주소·모델 | `KEVIN_OLLAMA_URL`, `KEVIN_OLLAMA_MODEL` |
| 제한 시간 | 기존 `KEVIN_OPENAI_TIMEOUT`, `KEVIN_OLLAMA_TIMEOUT` |

로컬 설정 화면은 이 컴퓨터의 localhost Ollama를 지원합니다.
웹 대화의 장면·게임·작곡 요청도 선택한 제공자와 모델을 사용합니다. 이전 웹 전용 agent 모델 변수는 이 공통 선택을 덮어쓰지 않습니다.
지킴이의 독립 로컬 추론과 카메라 분석, ElevenLabs/Windows 음성 연결은 별도입니다.

OpenAI 경로는 Responses API 구조화 출력·`store:false`와 로컬 계획 검증을 사용합니다.
`store:false`는 기본 모니터링 로그를 모두 없애는 옵션이 아닙니다.
참고: [Luna](https://developers.openai.com/api/docs/models/gpt-6-luna),
[구조화 출력](https://developers.openai.com/api/docs/guides/structured-outputs?api-mode=responses),
[API 데이터 정책](https://developers.openai.com/api/docs/guides/your-data).
