# KEVIN 독립 QA · 2026-11-07

## 평가 방식

Sol xhigh 3인이 기준 커밋 `2c4545f`를 각각 평가했다. 공통심사 50%(기술·상업성·팀 실행·스폰서 활용), 피어리뷰 50%(기술·API 활용·창의성·빌더 임팩트)의 각 항목을 동등 배점한다. 종합은 8항목 평균이며 기술은 두 기술 항목 평균이다. 실제 행사 심사 점수나 커밋 수에 대한 공식 배점 확인 결과가 아닌 모의 평가다.

| 기준 평가 | 종합 /100 | 기술 /100 | QA /1 | 판정 |
|---|---:|---:|---:|---|
| A | 69.125 | 58 | 0.638 | REVISE |
| B | 72.5 | 60.5 | 0.670 | REVISE |
| C | 71.5 | 63 | 0.710 | REVISE |

별도 Sol xhigh 사업성 검수는 57/100(REVISE)였다. 유료 구매자·반복 지불·설치/유지 원가·관찰 영수증의 추가 가치는 검증할 가설로 남긴다. 세 평가 평균에 별도 점수를 중복 합산하지 않았다.

ooo qa 기준 통합 판정은 `qa-a0e36c32` iteration 1, 0.58/1(REVISE)였다. 행동 실패를 관찰하면 높은 종합 점수로 통과시키지 않는다.

## 수정과 실증

- 계획 대기 및 방범 작업의 취소를 공유하고 정지 후 과거 작업의 후속 기기 명령을 차단했다.
- native BLE ACK 대기에 취소를 적용하고 native 화면 변경 후 장면 캐시를 무효화했다.
- 음량 0, 카메라 off를 보존하고 Host/Origin/JSON 요청 경계를 제한했다. 이 경계는 사용자 인증을 대신하지 않는다.
- 웹 HTTP 실패·정지 불명 결과를 성공으로 표시하지 않고 교차 Origin 카메라 감시를 복구했다.
- 청소 명령의 원격 적용 여부가 불명확하면 정지 성공을 주장하지 않는다. 실제 원격 실행을 되돌릴 수 있다는 보장은 없다.
- 자동 절약의 웹·CLI 경로에서도 `stopped` 확인 후에만 꺼졌다고 알린다.
- 문서는 진입점별 모델·인터넷·영수증 조건, 요청별 LIVE 선택, 가상/실물·계획 경로, 가격/원가/시장 추정의 한계를 구분했다.

`e488640` 관찰: Python 264개 통과, ASR 런타임 관련 2개 생략. 실제 pypixelcolor 라이브러리 계약 4개, Controller+가짜 기기 회귀 4개, HTTP 경계 14개 통과. Node 3/3 및 실제 Chromium 36/36 통과, uncaught 오류 0건. 전후 원시 로그·JSON은 로컬 `work/qa/`에 보존한다.

후속 `2bd7831` 웹 자동 절약 회귀 2개와 `67936df` Guardian 테스트 6개가 통과했다. 마지막 전체 스위트 결과는 완료 후 갱신한다. 앞선 전체 통과를 후속 변경의 전체 검증으로 간주하지 않는다.

실물 Windows·BLE·라디오 청취·실카메라·유료 API는 이번 독립 QA에서 실행하지 않았다. 가상 상대와 합성 영상 결과는 `physically_verified=false`다.

## 심사 대비

- 기술: “정지했는데 다시 움직이지 않는가?” 취소·지연 응답 회귀와 실패/불명 결과를 제시한다. 연결 단절 시 물리 정지 보장을 주장하지 않는다.
- 사업: “누가 왜 반복 지불하는가?” 매장 첫 고객 가설과 [검증 계획](BUSINESS.md)을 제시하고 유료 전환·ROI를 미검증으로 답한다.

- 재사용·임팩트: [시연 범위](HACKATHON_DEMO.md)와 [심사 질문 대응](JUDGING.md)을 제시한다. 연결 재사용이 장치별 유지 원가를 없애지는 않는다.
