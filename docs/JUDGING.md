# 심사 질문에 대한 현재 답변

이 문서는 시연 설명을 위한 근거표이며 공식 심사 결과가 아닙니다. 구현·회귀 시험 통과와 실물 효과·사업 검증은 구분합니다. 상세 API 경로는 [API_EVIDENCE](API_EVIDENCE.md), 수익 가설은 [BUSINESS](BUSINESS.md)에 있습니다.

## “기기가 실제로 목표를 달성했나요?”

현재 실물 기록은 LED 전광판·라디오 중심이며, 확장 기기의 이번 시험은 가상 장치입니다. 영수증은 이미지 변화와 첨부 기록의 무결성을 확인합니다. 목표 의미·소리·외부에서 신뢰한 서명자 신원을 인증하지 않습니다. 실물 웹캠 영수증과 오탐/미탐의 체계적 실증은 아직 없습니다.

- 근거: [README 실물 기록](../README.md), [receipt.py](../src/receipt.py), [test_receipt.py](../tests/test_receipt.py), [실물 인수 절차](HACKATHON_DEMO.md).
- 다음 검증: 고정 ROI에서 실제 성공, 명령 무시, 조명만 변화, 사람 가림을 분리해 반복 촬영하고 사람이 라벨한 목표 결과와 대조합니다. 표본 수·오탐/미탐·누락을 함께 공개해야 하며, 현재 정확도 수치는 제시하지 않습니다.
